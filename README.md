# محمد مروان للتسويق العقاري — منصة إلكترونية

موقع عقاري عربي (RTL) كامل + لوحة تحكم + قاعدة بيانات PostgreSQL:
عقارات، طلبات عملاء، مدونة، صفحات، قوالب إعلان ديناميكية (PNG)، وسائط،
إعدادات موقع، SEO، وصلاحيات مستخدمين (مالك / مشرف / مسئول / موظف).

## التشغيل محلياً
```bash
npm install
cp .env.example .env   # عدّل القيم
npx drizzle-kit push   # إنشاء الجداول
npm run dev
```

## لوحة التحكم
- الرابط: `/admin/login`
- بيانات المالك الأولية تُضبط من `.env` (ADMIN_*) وتُنشأ تلقائياً عند أول تشغيل.
- تُغيَّر كلمة السر من: لوحة التحكم ← إعدادات الموقع ← تغيير كلمة المرور.

## النشر الخارجي (رابط دائم) — Vercel (مجاني)

المشروع جاهز للنشر كما هو. الخطوات:

1. **GitHub:** أنشئ مستودعاً (repository) وارفع ملفات المشروع
   (ملف `project-export.zip` المرفق يحتوي الملفات جاهزة للرفع — استبعده من المستودع بعد الرفع).
2. **Vercel:** `vercel.com` ← New Project ← اختر المستودع ← Deploy.
3. **قاعدة البيانات:** أنشئ PostgreSQL مجانياً (Neon أو Vercel Postgres)،
   وانسخ **رابط الـ Pooler** وضعه في `DATABASE_URL` داخل Vercel (Project → Settings → Environment Variables).
4. **تخزين الصور (Vercel فقط):** Vercel → Project → Storage → Add Blob Store (Public)
   ← انسخ الـ `BLOB_READ_WRITE_TOKEN` وضعه في Environment Variables.
5. أضف متغيرات `ADMIN_NAME / ADMIN_EMAIL / ADMIN_PHONE / ADMIN_PASSWORD` إن أردت تخصيص حساب المالك.
6. بعد النشر: افتح الموقع ← لوحة التحكم ← SEO ← ضع **الرابط الدائم** في
   «الرابط الأساسي للموقع» ثم احفظ. سيتحدث كل Canonical وSitemap تلقائياً.
   (الصور والشعارات تُستورد تلقائياً في مكتبة الوسائط عند أول تشغيل.)

## بديل: Railway / استضافة ذات قرص دائم
نفس الخطوات بدون Vercel Blob: أضف خدمة Node + PostgreSQL،
واضبط `DATABASE_URL` فقط.

## Google Search Console (النشر على جوجل)
1. `search.google.com/search-console` ← إضافة ملكية ← بادئة URL ← رابطك الدائم.
2. تحقق بوسم HTML (لصق الرمز في: لوحة التحكم ← SEO ← رمز تحقق Google Search Console).
3. أرسل خريطة الموقع: `sitemap.xml`.

## ملاحظات
- كل المحتوى (العقارات، المقالات، الأرقام، الصور) يُدار من لوحة التحكم دون لمس الكود.
- لا تُخزَّن كلمات السر في الواجهة؛ التحقق من الصلاحيات يتم عبر قاعدة البيانات.
